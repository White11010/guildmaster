# GuildMaster

Небольшая браузерная игра про управление гильдией наёмников. Вы нанимаете бойцов,
берёте контракты, отправляете отряды на задания и стараетесь день за днём удерживать
гильдию на плаву, а людей — в хорошем настроении.

## Об игре

Вы — глава только что основанной гильдии. Мир постоянно подкидывает новых наёмников для
найма и контракты для выполнения. Ваша задача — подбирать нужных людей под нужные задачи,
следить за денежным потоком и справляться с последствиями каждого решения. Прогресс
сохраняется локально в браузере, так что игру можно продолжить позже.

## Геймплей

- **Нанимайте наёмников** на Рынке найма. У каждого есть уровень, цена найма и
  еженедельная зарплата.
- **Берите контракты** с Доски контрактов. У контракта есть требуемая сила, награда,
  предоплата и срок, до которого его нужно начать.
- **Собирайте отряд.** Сила наёмника зависит от его уровня и текущей морали. Чтобы начать
  контракт, нужно набрать минимум 75% от требуемой силы.
- **Завершайте день.** Время идёт только когда вы завершаете день. В конце дня
  разрешаются активные контракты, выплачиваются зарплаты, наёмники «стареют», а в мире
  могут появиться новые предложения.
- **Следите за финансами.** Прогноз показывает движение денег на 7 дней вперёд: видно
  всплески зарплат и ожидаемый доход с контрактов до того, как они наступят.
- **Берегите мораль.** Невыплаченные зарплаты превращаются в долг, долг каждый день
  снижает мораль, а наёмник с нулевой моралью покидает гильдию — что бьёт по морали всех
  оставшихся.

### Исходы

- **Шанс успеха** контракта зависит от соотношения силы отряда и требуемой силы: ~50% при
  75% силы, ~90% при равной силе, 100% при двойном превосходстве.
- **Успех** приносит награду и поднимает мораль отряда; **провал** и **просрочка** —
  наоборот, снижают мораль.
- Если в день выплаты не хватает денег, недостача становится **долгом** перед наёмником —
  погасите его, пока мораль не обрушилась.

## Игровой цикл

1. Начните новую гильдию (или загрузите сохранение) из Меню.
2. Наймите наёмников и возьмите перспективные контракты.
3. Назначьте достаточно сильный отряд и запустите контракт.
4. Завершите день, чтобы разрешить контракты и выплатить зарплаты.
5. Погасите долги, отреагируйте на журнал событий — и так по кругу.

## Технологии

| Область | Выбор |
|---|---|
| Фреймворк | Vue 3 (`<script setup>` SFC) |
| Язык | TypeScript (`strict`) |
| Состояние | Pinia (Composition / `setup`-сторы) |
| Роутинг | Vue Router (ленивая загрузка маршрутов) |
| Сборка | Vite |
| Стили | SCSS |
| Тесты | Vitest + @vue/test-utils + jsdom |
| Качество | ESLint + Prettier |
| Сохранения | `localStorage` |

Проект построен по **Feature‑Sliced Design** (`app`, `pages`, `widgets`, `features`,
`entities`, `shared`). Бизнес‑логика живёт в Pinia‑сторах; тяжёлые модалки и страницы
разбиты на отдельные чанки через динамические импорты.

## Запуск

```bash
npm install
npm run dev
```

Прочие команды:

```bash
npm run build          # проверка типов + продакшен-сборка
npm run preview        # просмотр продакшен-сборки
npm run typecheck      # vue-tsc
npm run lint           # ESLint
npm run lint:fix       # ESLint --fix
npm run test           # один прогон Vitest
npm run test:watch     # Vitest в режиме watch
npm run test:coverage  # отчёт о покрытии
```
